# 用户研究执行模板

> 这是一份待执行模板，不是虚构的访谈结果。建议招募 8–12 位符合目标画像的真实用户。

## 筛选条件

- 过去三个月至少完成两次电商购物
- 曾浏览或购买跨境商品
- 覆盖高频买家、价格敏感用户和首次跨境买家

## 访谈提纲（30 分钟）

1. 回忆最近一次“想买但最终放弃”的商品，发生了什么？
2. 你如何判断一个陌生商品值不值得点开？
3. 到手价、配送、退换和评价中，哪个最影响决定？
4. 请完成“找到适合新加坡通勤的小型数码商品并下单”的可用性任务。
5. 哪一步最犹豫？你期待页面再解释什么？

# Market Loom 产品需求文档（MVP）

## 1. 背景与目标

跨境电商用户经常面对同质商品过多、到手价不清楚、购买理由不足的问题。本项目选择“商品发现 → 详情 → 加购 → 下单”作为核心路径，用编辑策展、市场筛选、明确履约信息和漏斗实验降低决策成本。

目标用户是 18–30 岁、使用中文界面、会在东南亚市场购买设计型生活方式商品的学生与初入职场者。

## 2. 用户问题

1. 搜索结果太多，难以判断哪些商品适合自己的市场和场景。
2. 详情页强调参数，却没有回答“为什么值得买”。
3. 税费、配送时间和退换承诺出现太晚，导致结算流失。

## 3. MVP 范围

- 中文搜索、分类和市场筛选
- 商品策展标签、场景化描述和详情弹层
- 本地购物车、免运费门槛、模拟结算与订单确认
- 商品列表、详情、加购、结算、订单五类事件
- 对照排序与价值排序的稳定 A/B 分流
- 演示漏斗和守护指标看板

不在 MVP：真实支付、账户系统、售后工单、推荐模型训练和真实跨境税费计算。

## 4. 验收标准

- 用户能在 30 秒内筛选并找到目标市场的商品。
- 商品详情明确展示价格、配送、退换与购买理由。
- 从详情到模拟订单的路径不超过三次主要点击。
- 空购物车不能创建订单，所有价格以整数分计算。
- 演示数据、真实采集和生产能力边界必须清楚标注。

## 5. 版本规划

- V1：当前离线作品集 MVP。
- V1.1：接入 Medusa Store API，增加真实库存和区域价格。
- V1.2：接入 PostHog，完成漏斗、回放、问卷和 Feature Flag。
- V2：基于实验结果迭代排序、详情信息层级和结算承诺。
